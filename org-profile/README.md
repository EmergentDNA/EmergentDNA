## Machine DNA

**Canonical genotype + studio meaning** for sources of uniqueness in generative works — not the artwork, palette, or physics. Same rules + same DNA reproduce the same world. Many **species** can coexist over time.

### Current (canonical)

| Resource | Role |
|----------|------|
| **[walhimer-studio/Machine-DNA](https://github.com/walhimer-studio/Machine-DNA)** | Reference repo: **[`docs/CHRONICLE.md`](https://github.com/walhimer-studio/Machine-DNA/blob/main/docs/CHRONICLE.md)** (meaning), **`docs/SPEC.md`** (Type 1/2/3 + `Rand`), **`src/emergent-dna-core.js`** (genotype only; no renderer, no audio). |
| **Releases** | Tagged versions (semver). Pin integrations to a release tag. |

**Three DNA types:** **Seeded** (integer seed → PRNG), **Relational** (viewer / co-presence input), **Hybrid** (seeded structure + intentional unseeded surface).

**Naming:** *Machine DNA* = preferred studio name. *Emergent DNA* = historical Document 5 / package name for the genotype code.

### Origin (short)

The practice grew from asking whether **DAO**-like autonomous organization applied to artwork — closer to **DNA** (identity, heredity, many bodies) than to a business plan. Emergent DNA named the genotype; Machine DNA names the full system.

### Works that use this (examples)

- **Centered / One Row**, **Bloom**, **Traveling Landscape** — Type 1 seeded species  
- **Surrender Machines** — Hybrid (structural seed); temperament of yield  
- Piece ecology & phenotype live in studio artwork repos (e.g. mark-walhimer.com / walhimer.github.io)
